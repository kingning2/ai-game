# WerewolfStage 狼人杀舞台

沉浸式对局画面：左右座位列（头像 + 座位号 + 竖排身份标签）+ 中央内容区 + 底部大字幕。配合 `rust/game` 引擎的上帝视角快照使用——引擎产出对局状态，调用方完成视角裁剪后交给本组件渲染。纯展示组件，零业务逻辑、零内部状态。

## 何时使用

- Agent 狼人杀对局观战页（视频画面式布局）
- 任何「两列选手 + 中央实况 + 底部字幕」的舞台式画面

## 代码演示

### 基础用法

12 名 Agent 分左右两列，狼人红标、好人黄标；阵亡座位置灰；中央为当前发言卡，底部为旁白大字幕。

## API

### WerewolfStageProps

| 属性            | 类型               | 默认值   | 说明                                               |
| --------------- | ------------------ | -------- | -------------------------------------------------- |
| `title`         | `string`           | —        | 舞台大标题（如「AI 狼人杀」）                      |
| `players`       | `WerewolfPlayer[]` | —        | 座位列表：按座位号排序，前半左列、后半右列         |
| `phase`         | `'night' \\        | 'day'`   | —                                                  | 对局阶段：夜晚叠蓝黑夜幕遮罩（淡入淡出）；缺省不渲染阶段 UI |
| `phaseLabel`    | `ReactNode`        | 内置文案 | 阶段横幅文案（标题下方胶囊，如"天黑请闭眼"）       |
| `caption`       | `ReactNode`        | —        | 底部大字幕（旁白 / 天亮宣言）                      |
| `backgroundUrl` | `string`           | —        | 背景图（森林插画等），cover 铺满；缺省为深色渐变底 |
| `children`      | `ReactNode`        | —        | 舞台中央内容：发言流 / 白天记录 / 交互面板         |
| `className`     | `string`           | —        | 追加到根元素的类名                                 |

### WerewolfPlayer

| 属性             | 类型       | 默认值  | 说明                                                                                                                  |
| ---------------- | ---------- | ------- | --------------------------------------------------------------------------------------------------------------------- |
| `seat`           | `number`   | —       | 座位号，1 起                                                                                                          |
| `name`           | `string`   | —       | 玩家名（Agent 名）                                                                                                    |
| `avatarSrc`      | `string`   | —       | 头像图（AI 选手 logo）                                                                                                |
| `avatarFallback` | `string`   | —       | 无图回退（emoji / 首字母），缺省取名字首字                                                                            |
| `roleLabel`      | `string`   | —       | 身份文案：狼人 / 预言家…（由调用方从角色档案下发）                                                                    |
| `roleTone`       | `'wolf' \\ | 'good'` | `'good'`                                                                                                              | 身份色调：狼人红、好人黄（与引擎 Camp 对齐） |
| `alive`          | `boolean`  | `true`  | `false` 时名字/头像/徽章置灰压暗（下放到子元素级），大号鲜红 X 叉盖头像不受滤镜影响                                   |
| `speaking`       | `boolean`  | `false` | 正在发言：全彩 + 轻微放大提层；**其余座位 brightness 压暗降饱和**（暗沉但可辨；暗底不宜用正片叠底，亮色会被乘进背景） |

### PlayerSeat（可独立使用）

单个座位：名字 + 座位号 + 头像 + 竖排身份标签。`side` 决定镜像方向——身份标签始终朝舞台中央（left 列标签在右，right 列在左）。

### RoleBadge（可独立使用）

竖排身份标签（`writing-mode: vertical-rl`），`tone`：`'wolf'`（红底白字）/ `'good'`（黄底黑字）。

## 设计说明

- **上帝视角**：本组件按「身份公开」渲染（视频复盘画面）；对局进行中需要保密时，由调用方在快照裁剪层把 `roleLabel` 替换为「？」即可，组件不内置保密逻辑
- **沉浸式用色**：舞台是视频画面风格，字幕条用绝对色 `black/60`、标题用 `yellow`（与 Lightbox 灯箱同一约定，不随主题切换）
- 引擎侧对应物：`rust/game` 的 `GameSummary`（存活/身份统计）+ `role::profile()`（身份文案与 emoji 档案）
